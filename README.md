# Vetor de Números em Java

## Descrição

Programa desenvolvido em Java que lê 5 números inteiros utilizando JOptionPane.

O programa realiza as seguintes operações:
- Identifica o maior número par
- Identifica o menor número ímpar
- Calcula a soma total dos números
- Calcula a média dos valores

## Como executar

1. Abra o projeto na IDE
2. Compile o programa
3. Execute a classe ProgramaVetor

## Exemplo de uso

Entrada:
5
8
3
10
7

Saída:
Maior número par: 10
Menor número ímpar: 3
Soma total: 33
Média: 6.6

## Tecnologias utilizadas

- Java 21
- JOptionPane
